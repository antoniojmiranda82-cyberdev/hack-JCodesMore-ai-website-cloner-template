# Vigil Inspired QA

## Build
Record production-build result, date, and any blocking errors.

## Desktop
Record viewport, layout issues, overflow, spacing, typography, and motion observations.

## Mobile
Record responsive behavior, touch interaction, navigation, overflow, and motion observations.

## Interactions
Record scroll, hover, click, transition, animation, and state behavior that was tested.

## Visual Differences
Document known differences between the reference and the reconstructed implementation. Prioritize structure, hierarchy, spacing, typography, responsive behavior, and motion rather than protected brand assets.

## Unsupported Behavior
Record Canvas/WebGL or other behavior that could not be reproduced or tested reliably.

## Commercialization Blockers
List any remaining third-party branding, source copy, trademarks, protected/unlicensed media, non-original naming, incomplete QA, or implementation dependencies that prevent this template from becoming commercially reusable.
